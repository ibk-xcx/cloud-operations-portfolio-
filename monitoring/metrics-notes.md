# Monitoring–Key Metrics Notes

## EC2
- CPUUtilization  
- StatusCheckFailed  
- NetworkIn/Out  
- DiskRead/Write
- Disk space usage (EBS volume capacity)
- Memory usage (via CloudWatch agent)  

## S3
- Bucket size  
- NumberOfObjects  
- Request metrics  

## Alarms
- CPU > 70%  
- Status check fail  
- Unusual billing spike  

## Why Monitoring Matters
- Detects incidents faster  
- Reduces downtime  
- Improves SLA performance
